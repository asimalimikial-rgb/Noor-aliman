## نبذة

**نور الإيمان** تطبيق أندرويد عربي صُمّم ليجمع أدوات العبادة اليومية في واجهة واحدة: مواقيت الصلاة والتنبيهات، الأذان بأصوات متعددة، مصحف المدينة، التفسير، أذكار الصباح والمساء، المسبحة الإلكترونية، والقبلة.

الإصدار **1.16.1** يضيف تنظيماً جديداً للإعدادات، وحفظاً أفضل للاختيارات، وتذكيراً قبل الصلاة بعشر دقائق، وتحسينات لشاشة الأذان والواجهة.

## المميزات

### 🕌 الصلاة والأذان
- عرض مواقيت الصلاة والتنبيهات.
- تعديل وقت كل صلاة بصورة مستقلة، بدقيقة واحدة في كل مرة، ضمن مدى ±180 دقيقة، مع الحفظ التلقائي وإعادة الضبط.
- أصوات أذان متعددة، منها Aqib والأذان القصير وأزمور ومكة والدوحة.
- **خمسة تسجيلات من الدوحة، قطر**؛ تسجيل مستقل للفجر والظهر والعصر والمغرب والعشاء.
- نافذة أذان كاملة الشاشة بتصميم أخضر وذهبي، مع زر إيقاف واضح.
- إيقاف الأذان من التطبيق أو الإشعار، مع خيارات التحكم المدعومة في الإصدار.
- ظهور نافذة الأذان على شاشة القفل يعتمد على إصدار أندرويد وأذونات الجهاز وسياساته.

### 📖 القرآن والتفسير
- مصحف المدينة، 604 صفحات.
- اختيار القارئ وتكرار التلاوة وضبط السرعة.
- ثلاثة مصادر للتفسير: تفسير السعدي، والتفسير المختصر، والسراج في غريب القرآن.
- بيانات التفسير مضمّنة محلياً؛ بث التلاوات أو تنزيلها قد يحتاج إلى الإنترنت.

### 🤲 الأذكار والقبلة
- أذكار الصباح والمساء مع عدّاد للتقدم.
- مسبحة إلكترونية وتنبيه عند إكمال 33 تسبيحة.
- ذكر صوتي دوري للتسبيح والتحميد والتكبير والصلاة على النبي ﷺ.
- بوصلة لتحديد اتجاه القبلة، وتتأثر دقتها بحساسات الهاتف والمعايرة.

## الجديد في الإصدار 1.16.1

1. تنظيم الإعدادات في صفحة مستقلة بأقسام رئيسية وإعدادات فرعية قابلة للفتح والإغلاق.
2. حفظ اختيارات الأذان والإعدادات واستعادتها عند إعادة فتح التطبيق.
3. جعل أذان الدوحة الاختيار الافتراضي عند التثبيت الجديد، مع احترام تغيير المستخدم.
4. إضافة تذكير قبل الصلاة بعشر دقائق بصوت إشعار Android عادي، دون تشغيل الأذان الكامل.
5. تحسين وضوح عدّاد التسبيح في الوضع الليلي.
6. تحسين واجهة التطبيق مع الحفاظ على هويته الخضراء والذهبية.
7. تحسين معالجة دورة حياة WebView والتعامل مع أخطاء إعادة الفتح؛ ويظل التحقق النهائي من رسالة مسح الذاكرة مطلوباً على جهاز فعلي.
8. تحسين إيقاف الأذان عند إطفاء الشاشة وإدارة نافذة الأذان.

> تم التحقق من نجاح خطوة بناء APK الموقّع والتحقق من توقيعه في GitHub Actions. الاختبار النهائي على أجهزة أندرويد فعلية يظل مطلوباً قبل اعتبار جميع الوظائف مختبرة ميدانياً.

## إصلاحات الاستقرار قيد المراجعة

- إصلاح محرف زائد قبل إعلان HTML في الموقع لتفادي Quirks Mode.
- استمرار جدولة تنبيهات الصلاة عند عدم توفر Exact Alarm عبر التنبيه غير الدقيق الذي قد يتأخر حسب قيود Android.
- إعادة جدولة تنبيهات الصلاة عند عودة التطبيق إلى الواجهة حتى عند غياب صلاحية Exact Alarm.
- لم تُعدّل تعريفات الصلاحيات أو تدفقات طلبها، ولم تتغير ملفات الصوت أو إعداداتها.

هذه التغييرات موجودة في فرع مراجعة ولم تُدمج بعد؛ يلزم نجاح بناء Android والاختبارات على جهاز فعلي قبل اعتمادها أو نشر إصدار جديد.

## التطوير والبناء

يُبنى إصدار Release عبر GitHub Actions من فرع `main`. يتطلب البناء الموقّع إعداد GitHub Secrets التالية مسبقاً لدى مالك المستودع:
- `NOOR_ALIMAN_KEYSTORE_BASE64`
- `NOOR_ALIMAN_STORE_PASSWORD`
- `NOOR_ALIMAN_KEY_PASSWORD`

لا تضع ملف keystore أو كلمات المرور في المستودع.

لفحص المشروع محلياً:

```bash
./gradlew --no-daemon assembleDebug
```
